# GW Echo Search

This project investigates the presence of post-merger gravitational wave echoes in LIGO/Virgo data, using open-source tools such as GWpy and PyCBC. It aims to replicate and improve upon existing claims while exploring new detection strategies.

## Directory Structure
- `data/`: LIGO data
- `notebooks/`: Analysis notebooks
- `src/`: Core processing scripts
- `results/`: Echo search outputs and plots
- `references/`: Literature and papers
